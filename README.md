# Customer Spending and Repayment Analysis 

## Project Overview 
This project analyses customer Spending, Repayment behaviour, credit limits, product performance and customer segmentation

## Tools and Technologies 
- Python 
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Google Colab

## Project Objectives 
- Analyse customer spending patterns.
- Examine Repayment behaviour 
- Identify top spending customers
- Analyse product performance 
- Compare customer segments 
- Develop an interactive BI dashboard 

## Dataset Description 
- spend.csv: Customer spending transactions.
- Repayment.csv: Customer Repayment transactions
- Customer Acquisition.csv: Customer Information 

## Dashboard Features 
- Financial KPI cards
- Spending distribution 
- Product performance 
- Monthly spending and repayment trends
- Customer segmentation 
- Interactive filters 

## How to run the dashboard 
- Install the required libraries:
- pip install -r requirements.txt
- Run the application:
- streamlit run app.py
